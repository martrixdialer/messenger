# Martrix Messenger - HTML para GitHub Pages
Proyecto conectado a Firebase martrix-msg

## Pasos para publicar en GitHub
1. Crea repo en github.com/new nombre: messenger (vacío)
2. Ejecuta en esta carpeta:
```
git init
git add .
git commit -m "martrix messenger"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/messenger.git
git push -u origin main
```
3. GitHub > Settings > Pages > Branch: main / (root) > Save
Link: https://TU_USUARIO.github.io/messenger/

Importante: Activa Realtime Database en Firebase > Bases de datos y almac... > Crear > us-central1 > Modo prueba
